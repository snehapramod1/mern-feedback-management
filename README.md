MERN Stack Feedback Management System

About the Project

The MERN Stack Feedback Management System is a web application developed to manage feedback efficiently. It provides a dashboard to view and manage feedback records using CRUD operations.

Technologies Used

- MongoDB Atlas – Database
- Express.js – Backend framework
- React.js – Frontend library
- Node.js – Server environment

Project Structure

- "backend/" – Handles server-side operations and database connectivity.
- "frontend/" – Contains the user interface.
- "feedback-admin/" – Contains the feedback administration panel.

Features

- Feedback management
- Dashboard interface
- CRUD operations (Create, Read, Update, Delete)
- MongoDB database integration
- React-based user interface

Installation and Setup

1. Clone the Repository

git clone https://github.com/snehapramod1/mern-feedback-management.git

2. Navigate to the Project

cd mern-feedback-management

3. Install Backend Dependencies

cd backend
npm install

4. Configure Environment Variables

Create a ".env" file inside the "backend" folder and add your MongoDB connection string and other required settings.

Never upload your ".env" file or database password to GitHub.

5. Start the Backend

npm start

6. Run the Frontend

Open the appropriate frontend folder in a separate terminal, install its dependencies using "npm install", and run the start command specified in its "package.json".
